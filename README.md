# Simple Personal Assistant

A voice-controlled personal assistant built with Python. The assistant listens to voice commands, performs basic tasks, and provides audio responses using text-to-speech.

## Features
- Recognizes voice commands
- Responds using text-to-speech
- Tells the current time
- Searches the web
- Opens a web browser
- Opens the calculator
- Responds to greetings and exit commands

## Technologies
- Python
- SpeechRecognition
- pyttsx3
- datetime
- webbrowser
- subprocess
